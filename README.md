# svitlo-calendar

Графік відключень світла з Telegram-каналу -> твій Google Calendar зі сповіщеннями **за 10 хвилин до вимкнення і до увімкнення**.

- Джерело - публічний канал [@SvitloHolovanivskohoRayonu](https://t.me/s/SvitloHolovanivskohoRayonu) (читається без логіна, юзербот не потрібен).
- Черга - **2.2**, календар - **"Світло 2.2"** (створюється сам), вікно - **сьогодні і завтра**. Усе це можна змінити, див. "Налаштування".
- Працює в **Google Apps Script** - це безкоштовний "хостинг скриптів" у твоєму Google-акаунті: код живе там, запускається за таймером кожні 5 хвилин і пише в календар від твого імені. Свого сервера немає, Mac може бути вимкнений.
- Архітектура і чому саме так - [docs/architecture.md](docs/architecture.md).

## Як це працює

Кожні 5 хв скрипт робить таке:

1. Читає `t.me/s/<канал>`.
2. Нові або відредаговані пости з рядками `Черга N.N:` надсилає в **Gemini**. Той визначає тип поста і дату, на яку діє графік: дата в шапці "Зміни на 22:13 04.11" не те саме, що дата графіка.
3. Звіряє години з regex-розбором рядка `Черга 2.2: ...`. Якщо вони не збіглися, пост пропускає і пише помилку в `status`.
4. Склеює суміжні інтервали (`10-12, 12-14` -> 10:00-14:00, `22-24` + завтра `00-02` -> одне вимкнення).
5. Звіряє з календарем: нове створює, зникле видаляє, однакове не чіпає, тож дублів немає.

На кожне вимкнення ставить дві події:

| Подія | Коли | Нагадування |
|---|---|---|
| "Світла немає (2.2)" | весь інтервал, напр. 18:00-20:00 | о 17:50 |
| "Світло повертається (2.2)" | 20:00, 15 хв | о 19:50 |

## Скільки коштує

**0.** Apps Script безкоштовний. Скрипт витрачає приблизно 10-25 хв роботи на добу з 90 доступних для звичайного Gmail-акаунта і близько 300 HTTP-запитів з 20 000. Gemini викликається лише на нових постах з графіком (кілька разів на добу) і рахується на ключ з `.env` - це копійки.

## Встановлення (один раз, ~10 хв)

Потрібні лише Node.js (вже є: `node -v`) і твій Gmail.

1. **Увімкни Apps Script API** для свого акаунта: відкрий https://script.google.com/home/usersettings (під Gmail, яким логінитимешся) -> "Google Apps Script API" -> **On**.
2. **Залогінься** у clasp (офіційний CLI Google для Apps Script):
   ```bash
   cd ~/antigravity/svitlo-calendar
   npx @google/clasp@3 login
   ```
   Відкриється браузер - обери свій Gmail і натисни "Allow".
3. **Залий код:**
   ```bash
   ./deploy.sh
   ```
   Перший раз скрипт створить проєкт "Svitlo calendar" у твоєму акаунті (`.clasp.json`), візьме `GEMINI_API_KEY` з `../records/.env` і зальє код. Інший `.env` можна вказати так: `ENV_FILE=/шлях/.env ./deploy.sh`.
4. **Запусти `setup`:**
   ```bash
   npx @google/clasp@3 open-script
   ```
   У редакторі зверху вибери функцію **`setup`** -> **Run**. Google попросить дозволи:
   - "Review permissions" -> обери свій Gmail;
   - "Google hasn't verified this app" - це нормально, бо це твій власний скрипт: **Advanced** -> **Go to Svitlo calendar (unsafe)**;
   - **Allow** - доступ до календаря, зовнішніх запитів і таймерів.

   `setup` створить календар "Світло 2.2", увімкне таймер "кожні 5 хв" і одразу зробить перший прогін. Результат видно в "Execution log" унизу.
5. **Перевір** - у [Google Calendar](https://calendar.google.com) з'явиться календар "Світло 2.2" з подіями на сьогодні (ті, що ще не закінчились).
6. **Телефон** - найпростіше через застосунок **Google Calendar** під тим самим акаунтом. У налаштуваннях застосунку перевір, що календар "Світло 2.2" увімкнений і сповіщення дозволені.
   - Якщо користуєшся Apple Calendar на iPhone, увімкни календар на https://calendar.google.com/calendar/syncselect.

Далі нічого запускати не треба: таймер працює в Google, навіть коли Mac вимкнений.

## Щоденне використання

Нічого робити не треба. Коли в каналі з'являється графік на завтра або зміни на сьогодні, протягом 5 хв календар оновлюється сам.

Функції в редакторі (`npx @google/clasp@3 open-script`, вибрати функцію -> Run):

| Функція | Що робить |
|---|---|
| `setup` | Дозволи, календар, таймер і перший прогін. Запусти повторно після зміни `CHECK_EVERY_MIN` |
| `run` | Один прогін вручну (те саме, що робить таймер) |
| `status` | Показує в лозі графіки на дати, останні помилки, налаштування |
| `cleanup` | Видаляє всі майбутні події скрипта з календаря |
| `stop` | Вимикає таймер |

Логи всіх запусків - у редакторі, ліва панель **Executions**. Якщо запуск упав, Google сам надішле лист на Gmail. За замовчуванням - раз на добу, а в **Triggers** -> тригер `run` -> "Failure notification settings" можна поставити "Notify me immediately".

## Налаштування

Без зміни коду: редактор -> **Project Settings** (шестірня зліва) -> **Script Properties** -> **Add script property**. Значення звідти мають пріоритет над [src/config.gs](src/config.gs).

| Ключ | За замовчуванням | Що означає |
|---|---|---|
| `CHANNEL` | `SvitloHolovanivskohoRayonu` | Публічний канал (те, що після `t.me/`) |
| `QUEUE` | `2.2` | Черга ГПВ |
| `CALENDAR` | `Світло 2.2` | Назва календаря (якщо такого немає, створиться) або ID наявного календаря (з `@`, напр. твій Gmail - основний календар) |
| `REMIND_MIN` | `10` | За скільки хвилин нагадувати |
| `DAYS` | `2` | Скільки днів вести: сьогодні + завтра |
| `TITLE_OFF` / `TITLE_ON` | `Світла немає` / `Світло повертається` | Назви подій |
| `ON_EVENT_MIN` | `15` | Тривалість події "Світло повертається" |
| `CHECK_EVERY_MIN` | `5` | Як часто перевіряти: 1, 5, 10, 15 або 30 (після зміни запусти `setup`) |
| `GEMINI_MODEL` | `gemini-3.8-flash` | Модель Gemini |
| `GEMINI_API_KEY` | з `.env` через `deploy.sh` | Можна задати тут замість `.env` |

**Змінити чергу або канал:** зміни `QUEUE` / `CHANNEL`, потім запусти `cleanup`, щоб прибрати події старої черги, і `run`. Пости, вже прочитані для старої черги, будуть перечитані для нової.

**Змінити календар:** спершу `cleanup`, потім зміни `CALENDAR`, потім `run`.

## Розробка і перевірка локально

```bash
TZ=Europe/Kyiv node --test tests/core.test.js   # тести розбору і синхронізації на 20 реальних постах
TZ=Europe/Kyiv node tools/dry-run.js            # живий канал + Gemini, без календаря: які події поставив би
```

- [src/core.gs](src/core.gs) - чиста логіка: розбір HTML, рядка черги, склейка інтервалів, diff (тестується в node).
- [src/main.gs](src/main.gs) - Apps Script: таймер, канал, Gemini, календар, стан у Script Properties.
- [src/config.gs](src/config.gs) - налаштування за замовчуванням.
- `src/secret.gs` - генерує `deploy.sh`, у git не потрапляє.

## Обмеження

- **СГАВ** (аварійні "В 06:10 застосовано СГАВ 1, 2 чергу") поки не обробляються. Канал пише про них уже після факту, тож нагадати за 10 хв неможливо.
- Якщо канал стане приватним або Telegram змінить верстку `t.me/s`, `run` почне падати з помилкою "постів не знайдено", і прийде лист від Google.
- Події, що вже закінчились, скрипт не чіпає. Подія, що йде зараз, видаляється лише тоді, коли її прибрали з графіка.
